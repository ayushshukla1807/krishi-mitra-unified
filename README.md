## 🏗️ Structure

This repository is organized into workspaces for streamlined development:

- **`apps/web`**: React 19 + Vite web platform for farmers (English/Hindi/Marathi support).
- **`apps/mobile`**: Flutter mobile application for field-based crop management.
- **`services/api`**: Node.js/Express backend service for centralized data and authentication.
- **`services/ai`**: Python FastAPI microservice running deep learning models for diagnosis.
- **`docs`**: Technical architecture and API documentation.

## 🚀 Development

### Start the Web Dashboard
```bash
npm run dev:web
```

### Start the Backend API
```bash
npm run dev:api
```

### Start the AI Service
```bash
npm run dev:ai
```
